# E0d substantive certification

The E0d promotion gate compares a migration-179 legacy replay with migration 180 by portable semantic identity rather than database-local BIGINT allocation.

Its receipt follows the reusable delta-fed shape:

`source delta -> projection atoms -> affected keys -> local reducer -> authority`

The hard gate covers source pronouns, mention/object supports, demand authority, export/lookup/provenance surfaces, candidates/resolutions, and affected/document interface authority. Multiplicity is preserved in every comparison.

Run `scripts/certify_e0d_anaphor_delta_projection.py` with a legacy 179 database and an E0d 180 database. Supplying replay commands also enables PostgreSQL function accounting for compatibility-adaptor calls, actual E0d semantic-projector calls, wall time, and function self/total time. Timing is evidence only and does not automatically assert a performance win.

Exit code 2 means semantic parity failed. Exit code 3 means the fixture did not contain at least two anaphor occurrences/demands. Zero means the substantive parity gate passed; it does not by itself claim a speedup.

## O/R/C/S/L/P/G/F

The certification receipt carries the same normalized proof frame as the Agda
owner.

| Axis | Runtime obligation |
| --- | --- |
| O | Legacy and delta-fed final authority are equal. |
| R | Projection is relation-valued and set-based. |
| C | Recursive semantic self-update is forbidden. |
| S | Only affected consumer keys enter local reduction. |
| L | Surface spelling remains evidence and cannot become witness identity. |
| P | Candidate evidence cannot promote an open demand to resolution. |
| G | Source interiors are not rescanned after delta materialization. |
| F | Projected anaphor demands remain open until explicit resolution. |

Migration 180 implements this shape as:

```text
changed closed sentence regions
-> one pronoun-occurrence relation
-> mention/object/support/export/demand projection atoms
-> affected sentence interfaces
-> local interface reduction
-> existing demand/candidate/authority publication
```

The compatibility trigger only extracts the changed sentence-region relation.
It does not define a second semantic authority.

## Change control

A later optimization may replace the physical realization again only when the
same portable authority observer remains exact. A lower call count, lower wall
time, or lower mutation count cannot waive any O/R/C/S/L/P/G/F gate.
